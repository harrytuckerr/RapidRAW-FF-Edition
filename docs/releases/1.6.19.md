# RapidRAW · FujiFilm Edition 1.6.19

Open a RAF, bring your own camera profiles, and make it yours. This is the **working Android ARM64 community build tested on a Samsung Fold**, published with the same APK used for that testing.

## Smoother editing and zoom

Since the previous public source update:

- Restored the dedicated **Profiles** tab.
- Reused the committed DCP base and retained preview pixels across eligible edits and interactive zoom requests.
- Kept a reusable fitted preview when a full-resolution zoom is too large for the cache.
- Reused compiled GPU programs when the preview grows, while replacing size-dependent resources.
- Stopped UI-only workspace changes from invalidating preview pixels, and reused an available larger preview for smaller views. The single-entry preview cache budget remains unchanged.

Fold user testing reports that the other editing and repeated-zoom lag now seems gone. **Initial DCP selection and switching profiles still take time** while development catches up. That remains a [lower-priority known limitation](https://github.com/harrytuckerr/RapidRAW-FF-Edition/issues/17); this feedback is not a controlled timing benchmark. A smaller view can continue using the higher-resolution preview already available.

## Install and source

Download the `.apk` for an ARM64 Android device. This is a **debug-signed community build**, marked as a GitHub prerelease. It uses the same package and signer as the preceding Fold test builds, allowing an in-place update. Android may ask you to allow installation from your browser or file manager.

The attached source archive contains the application and pinned RAW engine inputs used for this APK. Artifact source: [`2a7a9d8b`](https://github.com/harrytuckerr/RapidRAW-FF-Edition/commit/2a7a9d8b5dcf35b13c1c881e29c5cd31d4eb96fe). The release tag adds documentation only to that application code. `SHA256SUMS.txt` covers both downloads. Proprietary Cobalt profiles and Looks are not included.

## Validation scope

Five focused native cases passed on the current source. Six additional native cases, 119 frontend cases and 10 browser layout cases have retained passing results; they were not rerun for 1.6.19. Package, signature, ARM64, resources, runtime-library and corresponding-source checks passed. In-place Fold installation, installed APK bytes and normal launch were verified.

The inherited TypeScript diagnostic baseline remains unresolved ([tracking issue](https://github.com/harrytuckerr/RapidRAW-FF-Edition/issues/1)); a clean full-project quality gate is not claimed. This release does not add desktop validation or establish colour or performance parity with other editors.
