## Changes since the public source update

- Corrected CPU DCP hue/saturation table coordinates. The user confirmed the colour issue was fixed on 1.6.20; this does not establish parity with Adobe or other editors.
- Added explicit unfinished ordinary AI-mask state and guarded asynchronous completion/cancellation. Valid completed bitmaps remain strict; legacy unmarked missing-payload edits are not silently repaired.
- Reduced Subject setup work with requested-family session initialization and borrowed reference pixels; released temporary refinement buffers earlier. These mitigations do not guarantee low peak memory or prevent all crashes.
- Separated current mask rendering from reusable preview pixels. Mask changes and exposure edits can reuse an eligible base while refreshing bitmap data and uniforms; reference-dependent masks keep their guarded path.
- Reused compiled GPU programs on growth and across the fit-to-editor transition, while recreating data resources. Preserved existing single-entry preview budget and source/profile/quality guards.
- Removed one unnecessary full RGB copy when selected accurate opening owns its base and has no AI patches. RAW demosaic, DCP colour and false-colour-filter quality are unchanged; fewer RAW passes are not claimed.

## Evidence and limits

P25 user feedback reported markedly better editing and zoom; five captured cache hits supported reuse on that observed path. P26 logs showed GPU program reuse, while opening still took about 10 seconds by user report. These observations are separate from P27 acceptance.

For P27, the focused owned-base CPU case and actual offscreen-GPU fit→accurate→editor case passed. Package/signature/ARM64/library/resource checks passed, and an in-place Fold install was verified. Earlier frontend/browser and native results are retained unchanged-path evidence, not newly rerun suites. Inherited frontend typecheck/CI failures remain unresolved; no all-platform or full-suite clean result is claimed.

One Subject operation completed in 11.78 seconds on P24. Existing low-memory exits, Subject crashes and masked-preview delays remain open risks. Some saved edits still fail with `DevelopmentFailed`; the exact affected-photo causes and backup-preserving recovery remain unresolved. Initial RAW/DCP opening, profile switching and colour-dropper limitations remain follow-ups. No automatic sidecar reset or missing-bitmap pruning is included.
